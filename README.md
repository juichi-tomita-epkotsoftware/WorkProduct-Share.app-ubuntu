# Share.app — シェアハウス住民向け管理Webアプリ

## アプリ概要

大型の国際交流シェアハウス用のツールアプリ

入居者のプロフィールの一覧昨日で住民同士のコミニケーションのきっかけを生む効果や、ハウス内のリマインド投稿機能で住民同士が快適に共同生活をしていく効果を期待できる。

また、住民規則についてはLLMを用いたQ＆A機能があるので知りたい情報やルールの確認がスムーズに行える。


**主な目的**
- 新住民がスムーズに既住民と打ち解けること。そうすればクレームや住民同士のトラブルは当人同士で話し合いで解決できることが増えて管理会社の負担を減らせる。

- 過去のトラブルや困りごとを再発させないようにすること。Q＆A機能で住民が正式なルールを把握しやすくしたり、過去にリマインドされた内容(洗濯物を洗濯機に置きっぱなしにしない,食器洗ったら片づけて等)を新住民も確認しやすくしてトラブルを再発させないこと。

**想定ユーザー**

住民(一般ユーザー)
- 性別・国籍不問の50人規模のシェアハウスに住む20〜40代の住民

管理会社(管理ユーザー)
- 21個のシェアハウスを運営・管理する管理会社

## 実装済み機能

## 一般ユーザー側

### Resident（住民管理）ページ
- 自身の住民情報の編集機能
- 他住人のプロフィール閲覧機能

### Remind ページ
- 匿名でのリマインドの投稿機能
- 過去のリマインド内容の閲覧機能
- 一定量同じカテゴリのリマインドが溜まればグループLINEへの通知機能
- 過去リマインド確認するためのページネーション機能

### Q&A ページ
- 質問を入力すれば、管理会社が与えた情報に基づいて生成AIが回答を行う機能

## 管理ユーザー側

### Resident（住民管理）ページ
- 住民情報の閲覧機能
- 住民の追加・削除機能

### Remind ページ
- リマインド投稿の閲覧機能
- 過去リマインド確認するためのページネーション機能
- CSV出力機能

### Q&A ページ
- LLMへの掲示情報の編集機能


## 共通

### Home ページ
- 当日の天気表示（OpenWeatherMap API連携）
- 現住民の総数・国籍割合の表示機能

- ログイン・認証機能

## 工夫したポイント

### フールプルーフ設計

- 住民の削除ボタン・リマインド投稿ボタンに確認ダイアログを実装し、誤操作を防止。削除ボタンは赤色で視覚的にも区別しやすいよう構築。
- 年齢や国籍などにバリデーションを設置して指定の入力値以外をはじく。

### クロスブラウザ対応
- ブラウザごとのデフォルトCSSによる表示差異をリセットし、統一したUIを実現
### パフォーマンス

- WSL2 + Docker 環境において、bind mount するプロジェクトファイルの配置を
  Windows 側（/mnt/c）から Linux 側（~/）へ移行。9P プロトコル経由の
  ファイル I/O オーバーヘッドを解消し、リクエストの応答速度を改善
- N+1問題を解決するためEager Loadを活用してクエリ本数を減らした
